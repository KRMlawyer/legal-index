# فهرس المنشورات القانونية وحوكمة الشركات — النسخة الخامسة

تمت إعادة فحص **310 سجلًا** من ملف `data/tweets.js` داخل أرشيف الحساب. أُدرجت **221 مادة مهنية**، مع مراعاة أجزاء السلاسل والتعقيبات المهنية وعدم اعتبار الرد غير مهني تلقائيًا.

## الملفات
- `index.html`: فهرس مستقل يمكن فتحه محليًا أو رفعه إلى GitHub Pages.
- `posts.json` و`posts.csv`: سجلات المنشورات المهنية المفهرسة.
- `review_all_310.csv`: سجل تدقيق لجميع المنشورات الـ310 يتضمن التصنيف والقرار وسبب إدراجه/استبعاده.
- `template.html` و`build.py` و`additions.csv`: تحديث الفهرس بعد إضافة منشورات جديدة.

## منهج المراجعة
- إدراج المنشورات الأصلية المهنية من التصنيف السابق.
- استعادة أجزاء السلاسل المهنية ذات النص المكتوب التي كانت مستبعدة لأنها ردود على الحساب نفسه، وربطها بالمنشور الجذر.
- إدراج 11 تعقيبًا على حسابات أخرى يحوي مضمونًا قانونيًا أو حوكميًا مستقلًا.
- إبقاء إعادات النشر والمجاملات والمحتوى غير المتخصص والمرفقات التي يتطلب فهمها مشاهدة الصورة خارج الفهرس؛ دون حذفها من سجل المراجعة.
- يستند التصنيف إلى نص الأرشيف. لا يشمل تدقيقًا قانونيًا موضوعيًا لجميع الآراء ولا تدقيق المرفقات المصورة. ويمكن إعادة تصنيف أي سجل من خلال `review_all_310.csv`.

## التحديث الأسبوعي
يمكن إضافة سطر جديد إلى `additions.csv` يحوي رابط المنشور ونصه وتصنيفه، ثم تشغيل `python build.py` ورفع `index.html` المُحدث إلى الاستضافة. الإجراء غير تلقائي في X حتى ربط مصدر منشورات مرخص. الموعد المقترح السبت.

## الإحصاءات
عداد الزيارات الخارجي قد لا يظهر محليًا أو عند حجب الخدمة. لتفعيل تتبع متقدم، أضف معرّف تحليلات في `template.html` قبل البناء.
